# Бизнес-требования: Business Metrics Analyzer

## Бизнес-требования

| ID    | Требование                                                                                                                           | Источник              | Приоритет |
|-------|--------------------------------------------------------------------------------------------------------------------------------------|-----------------------|-----------|
| BR-01 | Сократить время подготовки управленческой отчётности (сейчас 2–3 дня при ручной работе в Excel) за счёт автоматизации                | Коммерческий директор | Must have |
| BR-02 | Обеспечить руководству оперативный доступ к ключевым показателям продаж                                                              | Коммерческий директор | Must have |
| BR-03 | Сократить объём ручных операций при подготовке управленческой отчётности за счёт автоматического расчёта ключевых показателей продаж | Коммерческий директор | Must have |

## Функциональные требования

| ID    | Требование                                                                                                                                | Связанная User Story | Приоритет   |
|-------|-------------------------------------------------------------------------------------------------------------------------------------------|----------------------|-------------|
| FR-01 | Система должна отображать на дашборде не менее 4 KPI: выручку, средний чек, конверсию и рентабельность                                    | US-01                | Must have   |
| FR-02 | Система должна автоматически рассчитывать 100% из 4 основных KPI после загрузки данных                                                    | US-01, US-03         | Must have   |
| FR-03 | Система должна позволять загружать файлы (CSV/Excel) с данными о продажах объёмом до 20 МБ                                                | US-03                | Must have   |
| FR-04 | Система должна поддерживать не менее 4 ролей пользователей: коммерческий директор, менеджер по продажам, аналитик и администратор системы | US-05                | Should have |
| FR-05 | Система должна экспортировать сформированный отчёт в формате Excel (.xlsx)                                                                | US-04                | Should have |
| FR-06 | Система должна формировать отчёт по основным KPI за выбранный период                                                                      | US-02                | Must have   |
| FR-07 | Система должна позволять фильтровать данные по менеджеру или подразделению                                                                | US-08                | Must have   |

## Нефункциональные требования

| ID     | Требование                                                                                       | Категория          | Метрика                                                                     |
|--------|--------------------------------------------------------------------------------------------------|--------------------|-----------------------------------------------------------------------------|
| NFR-01 | Загрузка файла объёмом до 20 МБ                                                                  | Производительность | ≤ 30 секунд                                                                 |
| NFR-02 | Расчёт KPI после загрузки данных                                                                 | Производительность | ≤ 2 минуты                                                                  |
| NFR-03 | Загрузка дашборда                                                                                | Производительность | ≤ 3 секунды                                                                 |
| NFR-04 | Формирование стандартного отчёта                                                                 | Производительность | ≤ 10 секунд                                                                 |
| NFR-05 | Экспорт отчёта в Excel                                                                           | Производительность | ≤ 15 секунд                                                                 |
| NFR-06 | Система должна разграничивать доступ пользователей к функциям и данным в соответствии с их ролью | Безопасность       | Пользователь имеет доступ только к функциям и данным, разрешённым его ролью |

## Ограничения

| ID    | Ограничение     | Описание                                                                            |
|-------|-----------------|-------------------------------------------------------------------------------------|
| CN-01 | Срок разработки | 6 недель, работа в рамках трёх двухнедельных спринтов                               |
| CN-02 | Тип решения     | Разрабатываемая система должна быть веб-приложением                                 |
| CN-03 | Формат экспорта | Результаты анализа экспортируются в Excel                                           |
| CN-04 | Состав поставки | К концу шестой недели подготовлены итоговая версия системы и проектная документация |
